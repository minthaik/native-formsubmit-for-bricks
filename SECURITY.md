# Security

Use this repository's **Security > Report a vulnerability** private reporting feature. Never post tokens, visitor data, attachments, credentials or raw provider responses in public issues.

Include plugin/PHP/WordPress/Bricks versions, a minimal synthetic reproduction and expected behavior. Use disposable localhost with provider calls intercepted. Do not test other people's forms or send unsolicited mail.

The latest published plugin version is supported; there is no guaranteed response SLA. Hosting limits, Bricks validation/storage and FormSubmit activation/filtering/mail delivery are external boundaries. Avoid real submission data in reports.
