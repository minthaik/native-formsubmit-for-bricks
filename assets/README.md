# Logo assets

Original independent logo: modular form blocks, a form sheet and a send arrow. Palette: midnight navy, teal, coral and white. No third-party logo is incorporated. These images use the repository's GPL-2.0-or-later license.

- `logo-master.png`: generated master, transparency preserved.
- `logo-1024.png`: reusable 1024-pixel export.
- `icon-256x256.png` and `icon-128x128.png`: WordPress.org directory exports.

Created using the built-in image-generation tool with this prompt:

> Original WordPress plugin icon for Native FormSubmit for Bricks, an independent native forms-to-email connector. One cohesive geometric symbol: a white form sheet, three modular blocks and an upward-right paper-plane/send arrow. Rounded geometry, precise flat edges, midnight navy tile, teal form accents, coral send accent. Generous margins, readable at small sizes, transparent outside the tile. No words, letters, mockup, watermark or borrowed Bricks/FormSubmit/WordPress identity.

Size exports use Lanczos downsampling with alpha preserved. Directory artwork belongs in the SVN top-level `assets/`, outside the installable plugin ZIP.

Polish pass: preserve the form, blocks and send arrow; clean the navy background by removing shadows and translucent artifacts. Preserve transparency only outside the rounded tile.
